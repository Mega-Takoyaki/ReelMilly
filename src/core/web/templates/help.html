Reelmilly 使用法

このページは別タブで開いています。マニュアルを見ながら、元のタブでアプリを操作できます。

1. 起動のしかた 2. 基本の流れ 3. 画像・動画を取り込む 4. 一覧画面 5. プレビュー 6. AI処理 7. 区分の承認 8. タグ・フォルダ 9. 設定 10. Fanvueへ投稿 11. キー操作一覧 12. 困ったとき

1. 起動のしかた

Reelmilly は2つのプログラムを別々のターミナルで動かします。

  • 画面（Web UI）: reelmilly web を起動し、ブラウザで http://127.0.0.1:8420/ を開きます。
  • ワーカー（AI処理・定期実行）: reelmilly watch を起動したままにします。sfw/nsfw判定や説明文生成といった時間のかかる処理は、このワーカーが裏で行います。

ワーカーが止まっていると、AI処理は「待機中」のまま進みません。一覧画面の上部に「ワーカー停止中」と表示されたら reelmilly watch を起動してください。どちらも Ctrl+C で停止できます。

2. 基本の流れ

  1. 画像・動画を取り込む（ステータス: analyzing）
  2. AI処理でsfw/nsfw判定と説明文・タグ生成を行う（両方そろうと pending_approval）
  3. 人が内容を確認して区分（sfw / suggestive / explicit）を承認する（ready）
  4. 承認済みのものがFanvueへ投稿される（posted）。投稿に失敗したものは failed_fanvue

AIの判定はあくまで参考値です。最終判断と承認は必ず人が行います。

3. 画像・動画を取り込む

  • ドラッグ&ドロップ: 一覧画面上部の枠に、画像・動画を複数まとめて落とします（クリックしてファイルを選ぶこともできます）。
  • フォルダに置く: data/library/inbox/ に置いて reelmilly ingest を実行します。設定で「inboxフォルダの自動取り込み」をオンにすると、watch が自動で取り込みます。

取り込んだ直後は analyzing で、AI処理はまだ行われません。次の「6. AI処理」で開始します。取り込みはコピーではなく移動です（元の場所からは無くなります）。

4. 一覧画面

  • 絞り込み: ステータス・区分・タグ・フォルダ・承認状態で絞れます。
  • サムネイルサイズ: 右上のスライダーで変更できます（次回も保持されます）。
  • 選択: 各画像左上のチェックで複数選択できます。「表示中をすべて選択」で絞り込んだ結果をまとめて選べます。選ぶと画面下部に操作メニューが出ます（タグ付与・フォルダ追加・区分の一括承認・AI処理の開始）。
  • 詳細を見る: 各画像右下の矢印アイコンから詳細画面へ移動します。
  • バッジ: ステータスと区分を表示します。AI処理が待機中/実行中の画像には「判定中…」「説明生成中…」と表示され、完了すると自動で表示が変わります。

5. プレビュー

一覧のサムネイルをクリックすると拡大表示されます。

  • 左右ボタン / ← → キー: サムネイルの並び順で前後の画像・動画に切り替えます。
  • Zoom スライダー: 画像の表示倍率を変えます（元の解像度を超えても拡大できます。拡大するとスクロールできます）。
  • 画像をもう一度クリック、または右上の×、背景のクリック、Esc で閉じます。
  • 動画は音声オフで自動再生され、閉じると停止します。

6. AI処理（判定・説明文・タグ）

AI処理は2種類あり、それぞれ別々に開始できます。

処理内容必要なもの
sfw/nsfw判定画像・動画がsfwかnsfwかを、確信度付きで自動判定します（結果はタグ sfw/nsfw にもなります）pip install -e ".[nsfw]"
説明文生成・タグ付与内容の説明文を作り、タグ候補を付けます。投稿文の元になります設定の「生成AI」（Claude / OpenAI / 自前ホスト型VLM）

開始のしかた

  • 一覧から（複数まとめて）: 画像を選択 → 下部メニューの「sfw/nsfw判定」または「説明文・タグ生成」。
  • 詳細画面から（1件）: 「AI処理」カードのボタン。再実行すると結果を上書きします。
  • 定期実行: 設定の「AI自動処理・タグ」で、時刻と対象（すべての未処理 / 直近N日以内の未処理）を指定します。
  • まとめて手動: ターミナルで reelmilly analyze（未処理を全部キューに積んで処理します）。

非同期で動きます

ボタンを押すと処理はキューに追加されるだけで、画面は待たされません。ワーカーが順番に処理し、1件終わるごとに画面の表示が更新され、右下にトースト通知が出ます（失敗した場合は理由付きで通知します）。他の画面を操作していても構いません。

自前ホスト型VLMをCPUで動かすと、1件あたり数分かかります。GPUがあれば自動的に使われます。

タグのカテゴリ

設定で「服装」「性別」「日本人か」「背景・ロケーション」などのカテゴリを指定すると、説明文生成時にカテゴリごとにタグが1つ付きます。

7. 区分の承認

詳細画面の「区分の承認」で、sfw / suggestive / explicit のいずれかを選んで「承認する」を押します。一覧では複数選択して「区分を一括承認」もできます。

  • 初期選択はAI判定からの推定です（nsfw → explicit）。suggestive かどうかはAIでは判別できないので、人が選んでください。
  • 承認すると pending_approval のものは ready（投稿準備完了）になります。
  • 承認していないものは、Fanvueへ自動投稿されません。

8. タグ・フォルダ

  • 詳細画面でタグ・フォルダの追加と削除ができます。一覧の選択メニューからは、複数にまとめて付与できます。
  • AIが付けたタグと手動のタグは、今のところ画面上で区別されません。
  • 一覧の絞り込みで、タグ・フォルダから探せます。

9. 設定

画面右上の「設定」は、タブで分かれています。

  • Fanvue: OAuthアプリの Client ID / Secret、ハンドル等を設定し、「Fanvueと連携する」を押します。秘密の値は画面に表示されず、空欄のまま保存すると変更されません。
  • Telegram: 値の保存のみ（連携機能は未実装です）。
  • 生成AI: APIキー、プロバイダー、モデル、システムプロンプト、投稿文の生成モード（auto / draft）。モデルは「接続して利用可能なモデルを取得」で、実際に使えるものの一覧から選びます。explicit の画像には自前ホスト型VLMを使ってください（Claude / OpenAI は拒否する可能性が高いため）。
  • AI自動処理・タグ: sfw/nsfw判定と説明文生成の定期実行（時刻・対象範囲）、タグのカテゴリ。
  • 自動取り込み: watch による inbox の自動取り込みのオン/オフ。

設定を変えたら、どのタブからでも一番下の「保存する」を押します（全タブの内容がまとめて保存されます）。

10. Fanvueへ投稿

承認済み（ready）で、投稿先にFanvueが指定されたものが対象です。

  • 手動: reelmilly run drop（--count 3 で最大3件、--kind image や --rating sfw で絞り込み）
  • 自動: config.yaml の cadence に時刻を書くと、reelmilly watch がその時刻以降に実行します（同じ日に二重には実行されません）。

投稿文が未設定のときは、説明文から自動生成されます（draft モードでは下書きとして保存され、詳細画面で確認・採用します）。

投稿前の確認は運用者の責任です。AI生成であることの明示と、登場人物が18歳未満に見えないことを、毎回目視で確認してください。

12. 困ったとき

AI処理がずっと「待機中」のまま
ワーカーが動いていません。別のターミナルで reelmilly watch を起動してください。
sfw/nsfw判定が「失敗」する
NSFW判定用のモデルが入っていない可能性があります。pip install -e ".[nsfw]" を実行してください。失敗の理由はトーストと詳細画面に出ます。
説明文生成が「失敗」する
設定の「生成AI」でプロバイダーとAPIキー（またはモデル）を確認してください。
承認待ち（pending_approval）にならない
sfw/nsfw判定と説明文生成の両方が完了すると承認待ちになります。詳細画面で、どちらが未実行か確認してください。
設定が反映されているか確認したい
ターミナルで reelmilly doctor を実行すると、ディレクトリ・DB・Fanvue接続の状態を確認できます。
