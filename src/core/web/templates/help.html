Reelmilly 使用法

このページは別タブで開いています。マニュアルを見ながら、元のタブでアプリを操作できます。

1. 起動のしかた 2. 基本の流れ 3. 画像・動画を取り込む 4. 一覧画面 5. プレビュー 6. AI処理 7. 区分の承認 7b. 詳細画面 8. タグ・フォルダ 8b. ごみ箱・投稿予定なし 8c. 透かし 8d. 破綻画像 8d2. 非表示 8e. 動画の編集 8f. 通知・履歴 8g. 重複の確認 9. 設定 10. Fanvueへ投稿 11. キー操作一覧 12. 困ったとき

1. 起動のしかた

Reelmilly は2つのプログラムを別々のターミナルで動かします。

  • 画面（Web UI）: reelmilly web を起動し、ブラウザで http://127.0.0.1:8420/ を開きます。
  • ワーカー（AI処理・定期実行）: reelmilly watch を起動したままにします。sfw/nsfw判定や説明文生成といった時間のかかる処理は、このワーカーが裏で行います。

ワーカーが止まっていると、AI処理は「待機中」のまま進みません。一覧画面の上部に「ワーカー停止中」と表示されたら reelmilly watch を起動してください。どちらも Ctrl+C で停止できます。

2. 基本の流れ

  1. 画像・動画を取り込む（ステータス: analyzing）
  2. AI処理でsfw/nsfw判定と説明文・タグ生成を行う（両方そろうと pending_approval）
  3. 人が内容を確認して区分（sfw / suggestive / explicit）を承認する（ready）
  4. 承認済み（ready）のものがFanvueへ投稿される。投稿の結果は、準備状態とは別に、投稿先ごとに「投稿済み」「失敗」として記録される

AIの判定はあくまで参考値です。最終判断と承認は必ず人が行います。

3. 画像・動画を取り込む

  • 画像アップロード: 一覧画面の右上にある「画像アップロード」ボタンからファイルを選びます（複数可）。
  • ドラッグ&ドロップ: サムネイルを表示しているエリア全体に、画像・動画を落とせます（ドラッグ中は枠が光ります）。
  • フォルダに置く: data/library/inbox/ に置いて reelmilly ingest を実行します。設定で「inboxフォルダの自動取り込み」をオンにすると、watch が自動で取り込みます。

取り込んだ直後は analyzing で、AI処理はまだ行われません。次の「6. AI処理」で開始します。取り込みはコピーではなく移動です（元の場所からは無くなります）。

ファイル名について: 取り込むと、ディスク上のファイル名は作品ID（<ID>.png など）にそろえられ、元のファイル名は作品の情報として記録されます。詳細画面に元のファイル名が表示され、「ダウンロード」を押すと元のファイル名で保存できます。Fanvue へ投稿するときも、元の名前は使わず、ID の名前で送ります。

4. 一覧画面

  • ジョブ状況（左上）: ワーカーの稼働状態、AI処理の「実行中」「待機」「失敗」の件数、進捗バー、いま処理中の作品と次の予定、アップロードの進み具合、次の定期実行の予定が見られます。
  • フォルダ作成 / 画像アップロード: ジョブ状況の右側のボタンです。
  • ファイルタイプ: 1階層目の「画像」「動画」を選ぶと、その拡張子すべてが対象になります。展開した2階層目で、「.png だけ」のように拡張子を個別に選ぶこともできます（実際にある拡張子だけが件数つきで並びます）。
  • 絞り込み: 関連する項目はまとめてあります（「状態・区分」＝ステータス・区分・AI判定・承認状態、「投稿」＝投稿予定・投稿状態）。選んだ条件は、一覧の上に「見出し: 値 ×」のチップで表示され、×でその条件だけ外せます。対象の項目: ステータス・区分・AI判定・承認状態・投稿予定・投稿状態・タグ・フォルダは、それぞれ複数選択できます。候補は、いま実際にある値だけが件数つきで並びます（区分が未承認の作品は「（未設定・未承認）」で探せます）（見出しをクリックしてチェックを入れると、その場で一覧が絞り込まれます。検索欄も、入力が止まると反映されます。URLにも反映されるので、再読み込みしても同じ絞り込みです）。同じ項目の中はどれか1つに合えばよく（OR）、項目どうしは「すべてに合う」ものに絞られます（AND）。ただし、1つの作品が複数持てるタグとフォルダは、パネルの上部で「すべて含む（AND）」と「いずれかを含む（OR）」を切り替えられます（既定は、タグがAND、フォルダがOR）。
  • 検索: 検索欄に言葉を入れると、AIが作った内容説明・タグ・元のファイル名から探します。空白で区切ると、すべての語を含むものに絞ります。
  • 全件をスクロールで見る: 一覧は200件ずつ読み込み、下へスクロールすると続きが自動で読み込まれます（検索・絞り込みを使っていれば、その条件のまま続きます）。件数は「400件を表示中（全405件）」のように出ます。ごみ箱も同じです。
  • 上部メニューのタブ: 下へスクロールして、ジョブ状況・アップロード・検索と絞り込み・サムネイルサイズが画面の外へ出ると、最上部の中央に「メニュー・絞り込み」の小さなタブが残ります。タブを押すと、そのメニューが重ねて開き、下の画像を見ている場所のまま、アップロードや絞り込み・検索ができます。もう一度タブを押す・メニューの外を押す・Escで閉じます。
  • サムネイルサイズ: 右上のスライダーで変更できます（次回も保持されます）。
  • サムネイルの形状（コンパクト / フル）: サムネイルサイズのスライダーの右にあるトグルで切り替えます。コンパクト（既定・オフ）は、すべて正方形に切り抜いて並べます。フル（オン）は、画像・動画の縦横比のまま表示します（縦長の画像も切れません）。並びは、コンパクトと同じく左から右へ、次の行へと進み、行ごとに高さをそろえます。選んだ形状は、次回も維持されます。
  • 並び順: ツールバーの「並び順」で、登録日時（新しい順・古い順）・更新日時・ファイル名・画像サイズから選べます（既定は登録日時の新しい順）。選んだ並び順は、URLにも反映されます。
  • フォルダ / フラット: 並び順の右のトグルで切り替えます。フォルダ（既定・オフ）は、フォルダを最上部に並べ（どの並び順でも最上部、名前順）、その下にはフォルダに入っていない作品を出します。フォルダを押すと、その中身を開きます（「フォルダの一覧へ戻る」で戻れます）。フラット（オン）は、フォルダの中身も含めて、すべての作品を並べます。検索や絞り込みを使っているときは、どちらでも、該当する作品がそのまま（フォルダの中のものも）出ます。
  • 選択: 各画像左上のチェックで複数選択できます。「表示中をすべて選択」で絞り込んだ結果をまとめて選べます。選ぶと画面下部に操作メニューが出ます（タグ付与・フォルダ追加・区分の一括承認・AI処理の開始）。
  • ドラッグで複数選択: チェックが入っている画像の上からマウスをドラッグすると、枠で囲んだ範囲の画像を選択できます（一覧・ごみ箱）。いったん離しても、次にまたチェックが入っている画像からドラッグすれば、選択を追加できます。チェックのない画像からのドラッグは何もしません。画面の端までドラッグすると自動でスクロールします。なお、一覧の画像をドラッグしても、アップロードにはなりません（アップロードは、パソコンのフォルダからファイルを落としたときだけです）。
  • 詳細を見る: 各画像右下の矢印アイコンから詳細画面へ移動します。
  • アイコン: サムネイルに小さなアイコンを重ねて表示します（下の「アイコンの見かた」）。マウスを乗せると説明が出ます。AI処理が待機中/実行中の画像は、該当するアイコンが点滅し、完了すると自動で表示が変わります。

アイコンの見かた

右上（左から）: 種別・sfw/nsfw

JPG 静止画（緑がかった青）。文字はファイルの拡張子です。
MP4 動画（紫）。
? 未処理（灰色の点線）。sfw/nsfw判定がまだありません。
S AIの自動判定が SFW（淡い緑の枠）。人の承認はまだです。
N AIの自動判定が NSFW（淡い赤の枠）。人の承認はまだです。
S 承認済みの sfw（濃い緑の塗りつぶし）。
S 承認済みの suggestive（濃い橙の塗りつぶし）。
N 承認済みの explicit（濃い赤の塗りつぶし）。

左下: ステータス（マウスを乗せると文字で表示されます）

赤: ANALYZING（未処理・分析中）
黄: PENDING_APPROVAL（AI処理が済み、承認待ち）
緑: READY（承認済み・投稿準備完了）

左下、丸の右: 投稿先のフラグ（投稿を試みた投稿先だけに出ます。未投稿なら何も出ません）

F Fanvue に投稿済み（青い塗りつぶし）。マウスを乗せると日時とURLが出ます。
X X に投稿済み（黒い塗りつぶし。X への投稿は未実装です）。
F 投稿に失敗（点線の紫の枠）。理由はマウスオーバーか詳細画面で確認でき、詳細画面の「再投稿の対象に戻す」で次回の投稿対象に戻せます。

作品の準備状態（丸の色）と、投稿状態（投稿先ごとのフラグ）は別々に管理されます。将来、投稿先が増えたら、フラグも増えます。

5. プレビュー

一覧のサムネイルをクリックすると拡大表示されます。

  • 左右ボタン / ← → キー: サムネイルの並び順で前後の画像・動画に切り替えます。
  • Zoom スライダー: 画像の表示倍率を変えます（元の解像度を超えても拡大できます。拡大するとスクロールできます）。
  • 画像をもう一度クリック、または右上の×、背景のクリック、Esc で閉じます。
  • 動画は音声オフで自動再生され、閉じると停止します。

6. AI処理（判定・説明文・タグ）

AI処理は2種類あり、それぞれ別々に開始できます。

処理内容必要なもの
sfw/nsfw判定画像・動画がsfwかnsfwかを、確信度付きで自動判定します（結果はタグ sfw/nsfw にもなります）pip install -e ".[nsfw]"
説明文生成・タグ付与内容の説明文を作り、タグ候補を付けます。投稿文の元になります設定の「生成AI」（Claude / OpenAI / 自前ホスト型VLM）

開始のしかた

  • 一覧から（複数まとめて）: 画像を選択 → 下部メニューの「sfw/nsfw判定」または「説明文・タグ生成」。
  • 詳細画面から（1件）: 「AI処理」カードのボタン。再実行すると結果を上書きします。
  • 定期実行: 設定の「AI自動処理・タグ」で、処理の種類・時刻・対象（すべての未処理 / 直近N日以内の未処理）を指定します。スケジュールは何件でも追加できます（例: 毎日03:00に全未処理、12:00に直近1日分だけ）。
  • まとめて手動: ターミナルで reelmilly analyze（未処理を全部キューに積んで処理します）。

非同期で動きます

ボタンを押すと処理はキューに追加されるだけで、画面は待たされません。ワーカーが順番に処理し、1件終わるごとに画面の表示が更新され、右下にトースト通知が出ます（失敗した場合は理由付きで通知します）。他の画面を操作していても構いません。

自前ホスト型VLMをCPUで動かすと、1件あたり数分かかります。GPUがあれば自動的に使われます。

タグのカテゴリ

設定で「服装」「性別」「日本人か」「背景・ロケーション」などのカテゴリを指定すると、説明文生成時にカテゴリごとにタグが1つ付きます。

7. 区分の承認

詳細画面の「区分の承認」で、sfw / suggestive / explicit のいずれかを選んで「承認する」を押します。一覧では複数選択して「区分を一括承認」もできます。

  • 初期選択はAI判定からの推定です（nsfw → explicit）。suggestive かどうかはAIでは判別できないので、人が選んでください。
  • 承認すると pending_approval のものは ready（投稿準備完了）になります。
  • 承認していないものは、Fanvueへ自動投稿されません。

7b. 作品の詳細画面

  • 操作メニュー（右上の「操作 ▾」）: 画像への操作をまとめています。AI処理（sfw/nsfw判定・説明文とタグの生成）、透かし（入れる・見る・外す）、ダウンロード、破綻画像のマーク、ごみ箱への移動です。
  • 投稿: 投稿先（Fanvue・X）ごとに、投稿予定（チェックを入れた投稿先だけが、SNS投稿の対象になります。チェックを入れ外しした瞬間に保存されます。すべてオフなら「投稿予定なし」）と、投稿状態（未投稿・投稿済み・失敗）を、1つの行で管理します。
  • 手動で投稿したとき: その行の「投稿済みとして記録…」で、投稿日時とURL（任意）を記録できます。記録した投稿先は「投稿済み」（手動で記録）になり、自動投稿の対象から外れるので、二重投稿を防げます。間違えたときは「記録を取り消す」で未投稿に戻せます。失敗した投稿は「再投稿の対象に戻す」で、次回の自動投稿の対象に戻せます。
  • 各項目の説明は、項目名の横の ⓘ にマウスを乗せる（クリックで固定）と表示されます。

8. タグ・フォルダ

  • 詳細画面でタグ・フォルダの追加と削除ができます。一覧の選択メニューからは、複数にまとめて付与できます。
  • AIが付けたタグと手動のタグは、今のところ画面上で区別されません。
  • 一覧の絞り込みで、タグ・フォルダから探せます。

8b. ごみ箱・投稿予定なし

ごみ箱

  • 一覧で作品を選び、下部メニューの「ごみ箱へ」を押すか、詳細画面の「この作品をごみ箱へ移動する」で、ごみ箱に入れられます。
  • ごみ箱の作品は、通常の一覧、SNS投稿、AI処理（待機中のものは取り消し）の対象から外れます。ファイルは削除されません。
  • 画面上部の「ごみ箱」（「一覧」の右）で中身を見られます。サムネイルから複数選んで「選択した作品を元に戻す」で復旧できます。
  • 完全に削除: ごみ箱画面で作品を選んで「選択した作品を完全に削除」、または「ごみ箱を空にする」を押します。ファイルと記録（タグ・フォルダ・投稿の記録など）が消え、元に戻せません（確認ダイアログが出ます）。AI処理の実行中の作品は、終わってから削除できます。

投稿予定なし

  • 作品ごとの「投稿先」（Fanvue / X）のチェックをすべてオフにすると「投稿予定なし」になり、どのSNS投稿の対象にもなりません。サムネイルには斜線の丸が出ます。
  • 詳細画面の「投稿先（投稿予定）」で、投稿先ごとにオン/オフできます。一覧では、選択して「投稿予定なしにする」「投稿予定に戻す」（Fanvue・Xに戻します）で一括変更できます。
  • 絞り込みの「投稿予定」で、あり/なしを探せます。

8c. 透かし（ウォーターマーク）

画像に、簡単には見えないほど薄い文字の透かし（例: @ai_hiyo）を入れられます。AI処理と同じく非同期のジョブで、画面は待たされません。

  • 入れ方: 一覧で作品を選んで下部メニューの「透かしを入れる…」、または詳細画面の「透かし」カードのボタンから、設定ダイアログを開きます。
  • 実行前に指定するもの: 透かしの文字、挿入位置（5×5の25か所から複数選択できます。「25か所すべて選択」ボタンと、「全面に繰り返す」もあります）、濃さ（不透明度。小さいほど薄い）、大きさ。この画面を開いている間は、前回の設定が初期値として引き継がれます。最初の値は、設定画面の「透かし」タブで編集できます（既定の文字は @GirlAidol。濃さ・大きさ・位置も指定できます）。
  • プレビュー: ダイアログに、実際の濃さのプレビューが出ます。薄いので、見えにくいときは画像を拡大して確認してください（既定は16%で、「簡単には見えない」目安です）。
  • 元のファイルは変わりません。透かし入りの別ファイル（watermarked.拡張子）を作ります。サムネイルには「透」のチップが付き、詳細画面の「透かし入りを見る」で、一覧のプレビューと同じポップアップで確認できます。
  • 投稿: 透かし入りのファイルがある作品は、Fanvue へ透かし入りを投稿します。
  • 「透かしを外す」で透かし入りファイルを削除し、元のファイルに戻せます。入れ直すときは上書きされます。
  • 画像のみ対応です（動画は未対応）。選択に動画が含まれていると、動画はスキップします。

8d. 破綻画像（キメラ）

  • AI生成特有の崩れ（手足・顔の破綻など）がある作品に、「破綻画像」のマークを付けられます。一覧で選んで「破綻画像にする」、または詳細画面の「破綻画像（キメラ）」から付け外しします。
  • マークした作品は、既定の一覧に表示されず、SNS投稿の対象とAI処理（定期実行を含む）の対象から外れます。ごみ箱とは別で、ファイルや記録はそのまま残ります。
  • 一覧のフィルタ「破綻画像」で、「含めて表示する」「破綻画像だけ表示する」に切り替えられます（表示中は、サムネイルに赤い「破」のチップが付きます）。

8d2. 非表示

  • 作品を既定の一覧に出さないだけにする印です。ごみ箱とも、破綻画像とも別で、ファイルも、投稿・AI処理の対象も変わりません。
  • つけかた: 一覧で作品を選んで、下部メニューの「非表示にする」。または、詳細画面の「操作」→「非表示にする」。戻すには「表示に戻す」/「非表示を解除する」。
  • 見かた: 一覧の絞り込みの「非表示」で、「含めて表示する」「非表示の作品だけ表示する」を選びます（非表示の作品には、小さな「隠」の印が付きます）。
  • フォルダ表示のフォルダの件数にも、非表示の作品は数えません。

8e. 動画の編集

  • 動画の作品の詳細画面にある「動画の編集」で、動画の前後を削除して切り出せます（テロップ・ロゴ・モザイクは、今後追加予定です）。
  • 元の動画は変わりません。結果は別の動画（サブ動画）として、1つの作品に最大10件まで登録できます（失敗したものは数えません）。
  • 切り出しかた: 動画を再生して、始めたい位置で「現在位置を開始に」、終わりたい位置で「現在位置を終了に」を押します（秒の数値を直接入力しても、時間軸のバーを押してその位置へ移動してもよいです）。「範囲をプレビュー」で、選んだ範囲だけを再生して確かめられます。
  • 正確（再エンコード）は、指定した位置ぴったりで切ります（数秒〜、動画の長さ程度かかります）。高速（再エンコードなし）は一瞬ですが、開始位置が少しずれることがあります。
  • 「切り出して、別の動画として保存」を押すと、待機中として登録され、少し待つと完了します（ワーカー reelmilly watch が処理します。AI処理が長く続いていても、編集は待たされません）。完了や失敗は、右上のベルの通知にも出ます。
  • 下の「編集した動画」の一覧に、どんな編集をしたか（例: トリム 0:02.0～0:05.0）・長さ・サイズが出ます。「動画を開く」で再生、「ダウンロード」で保存、「削除」でその編集動画だけを消せます。
  • 作品を完全に削除すると、編集動画も一緒に消えます。
  • ffmpeg が必要です（winget install Gyan.FFmpeg）。入っていないと、編集は登録できません。

8f. 通知・履歴

  • 画面右上のベルのアイコンに、時間のかかる処理や、画面を開いていないときに進む処理の完了通知が届きます（AI処理・透かし・投稿・アップロード・inboxの取り込み・2件以上の完全削除・重複の処理・ストレージの変化など）。1件のタグ付けや名前の変更のような、すぐ終わる操作は通知しません。未読があると、ベルが点滅して件数が出ます。
  • ベルを押すと最新の10件が開き、開くと既読になります。「すべての履歴を見る」で、設定画面の「通知・ログ」タブへ移ります。
  • 設定の「通知・ログ」タブには、全件の履歴があります（種類で絞り込み、ページ送りできます）。
  • 重複の通知には「確認する」ボタンがあり、そこから重複の確認ダイアログを開けます。

8g. 重複の確認

  • ファイルの中身が完全に同じ画像・動画を「重複」として扱います（ごみ箱の中のものも含みます）。縮小・再エンコードなどで中身が変わったもの、見た目が似ているだけのものは、別のファイルとして扱います。
  • アップロードしたとき: 既にあるものと同じファイルは、取り込まずに保留にして、確認ダイアログが開きます。「取り込まない」か「別の作品として取り込む」を1件ずつ、または「すべて取り込まない／すべて取り込む」でまとめて決められます。「あとで決める」で閉じても、保留は残り（48時間で自動的に片付きます）、ベルの通知などから開き直せます。
  • 登録済みの重複（inboxからの取り込みなどで後から増えたもの）は、定期処理で検出して通知します。ダイアログで、組ごとに「残す1つ」を選んで他をごみ箱へ移すか、「すべて残す」かを、まとめて決められます。「すべて残す」と決めた組は、二度と通知しません。残す候補の初期値は、投稿済み・承認済み・タグが多いものを優先します。

9. 設定

画面右上の「設定」は、タブで分かれています。

  • Fanvue: OAuthアプリの Client ID / Secret、ハンドル等を設定し、「Fanvueと連携する」を押します。秘密の値は画面に表示されず、空欄のまま保存すると変更されません。
  • Telegram: 値の保存のみ（連携機能は未実装です）。
  • 生成AI: APIキー、プロバイダー、モデル、システムプロンプト、投稿文の生成モード（auto / draft）。モデルは「接続して利用可能なモデルを取得」で、実際に使えるものの一覧から選びます。explicit の画像には自前ホスト型VLMを使ってください（Claude / OpenAI は拒否する可能性が高いため）。
  • ストレージ: 画像・動画のファイルを置く場所を、任意のドライブ・フォルダ（USBメモリ・外付けディスクなどのリムーバブルメディアも可）へ変えられます。「フォルダを選ぶ…」やドライブのボタンから選び、「コピーして移す」（推奨）か、「すでにファイルがある場所を使う」（ドライブ文字が変わったときなど）で切り替えます。メディアが外れていても、アプリは画像なしで起動し、画面上部に警告が出ます（取り込み・AI処理・投稿は止まり、待機中の処理は残ります）。つなぎ直すと再開します。データベースは常にこのPC内にあります。
  • AI自動処理・タグ: sfw/nsfw判定と説明文生成の定期実行（時刻・対象範囲）、タグのカテゴリ。
  • 自動取り込み: watch による inbox の自動取り込みのオン/オフ。
  • 通知・ログ: 処理の通知の全履歴（種類で絞り込み）。

設定を変えたら、どのタブからでも一番下の「保存する」を押します（全タブの内容がまとめて保存されます）。

10. Fanvueへ投稿

承認済み（ready）で、投稿先にFanvueが指定されたものが対象です。

  • 手動: reelmilly run drop（--count 3 で最大3件、--kind image や --rating sfw で絞り込み）
  • 自動: config.yaml の cadence に時刻を書くと、reelmilly watch がその時刻以降に実行します（同じ日に二重には実行されません）。

投稿文が未設定のときは、説明文から自動生成されます（draft モードでは下書きとして保存され、詳細画面で確認・採用します）。

投稿前の確認は運用者の責任です。AI生成であることの明示と、登場人物が18歳未満に見えないことを、毎回目視で確認してください。

12. 困ったとき

「画像・動画のストレージを使えません」と出る
画像の置き場所（USBメモリ等）が見つかりません。接続を確認してください。ドライブ文字が変わっていたら、設定の「ストレージ」で「すでにファイルがある場所を使う」を選び、新しい場所を指定します。
画面が開かない（サーバーが止まっている）
web と watch は、終了しても10秒後に自動で再起動します。それでも開かないときは、デスクトップのショートカット（scripts\start-reelmilly.bat）で起動し直してください。止まった理由は data\logs\web.log・data\logs\watch.log に残ります（「exited ... (code …)」の行があれば異常終了、起動の行のあとに何も無ければ、ウィンドウを閉じたか外から止められたものです）。
AI処理がずっと「待機中」のまま
ワーカーが動いていません。別のターミナルで reelmilly watch を起動してください。
sfw/nsfw判定が「失敗」する
NSFW判定用のモデルが入っていない可能性があります。pip install -e ".[nsfw]" を実行してください。失敗の理由はトーストと詳細画面に出ます。
説明文生成が「失敗」する
設定の「生成AI」でプロバイダーとAPIキー（またはモデル）を確認してください。
承認待ち（pending_approval）にならない
sfw/nsfw判定と説明文生成の両方が完了すると承認待ちになります。詳細画面で、どちらが未実行か確認してください。
設定が反映されているか確認したい
ターミナルで reelmilly doctor を実行すると、ディレクトリ・DB・Fanvue接続の状態を確認できます。
