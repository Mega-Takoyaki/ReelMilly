# 0016. SNS/生成AIの接続設定（アカウント名・APIキー）を本体UIから編集可能にする

- ステータス: 決定
- 決定日: 2026-09-26
- 決定者: プロジェクトオーナー

## コンテキストと課題

これまでFanvue APIトークン・ハンドル・生成AIのAPIキー等は`.env`ファイルを手動編集する運用だった（README「秘密情報は`.env`のみに置く」）。プロジェクトオーナーより、Fanvueをはじめとする各SNS向けの接続設定（アカウント名・APIキー等）を本体UIの画面から設定できるようにしたいという要望があった。

## 検討した選択肢

| 選択肢 | 特徴 |
|---|---|
| SQLiteの`settings`テーブルに保存（[ADR-0015](0015-ai-content-description-and-caption-generation.md)のシステムプロンプト等と同じ場所） | 実装は単純だが、「秘密情報は`.env`のみ」という既存方針と矛盾する。DBファイル（`data/state/reelmilly.db`）もリポジトリには含まれないため実害は小さいが、方針の一貫性が崩れる |
| `.env`ファイルをWeb UIから読み書きする | 既存の「秘密情報は`.env`のみ」という方針を維持したまま、UIからの編集を実現できる |

## 決定

`.env`ファイルを本体UIから直接読み書きする方式を採用する。`core/env_settings.py`が`python-dotenv`の`dotenv_values`/`set_key`を使い、`/settings`ページの「接続設定」セクションから以下の項目を編集できるようにする。

- Fanvue: APIトークン、ハンドル（アカウント名）、投稿URLテンプレート、APIベースURL、APIバージョン
- Telegram: Botトークン、許可チャットID（Telegram連携自体は未実装のため、値の保存のみ可能）
- 生成AI: Anthropic(Claude) APIキー、OpenAI APIキー（[ADR-0015](0015-ai-content-description-and-caption-generation.md)）

### 秘密情報の扱い

- APIトークン等の秘密情報は画面に値を表示しない（「設定済み」／「未設定」のみ表示）。入力欄を空欄のまま保存すると既存の値は変更しない（誤って空値で上書きしてしまうことを防ぐ）
- 非秘密項目（ハンドル、URL等）は現在値を表示し、通常のテキスト入力として編集できる
- 保存後は同一プロセス内の環境変数（`os.environ`）にも即座に反映する（`load_dotenv(..., override=True)`）ため、`reelmilly web`を再起動しなくても次回の投稿ジョブ実行等から新しい値が使われる
- 実際に接続できるかどうかの検証は行わない（保存できることと接続できることは別）。疎通確認は引き続き`reelmilly doctor`で行う

X（旧Twitter）は未実装のため対象外。実装時に本ページへ追加する。

## 結果

### 良い影響

- 「秘密情報は`.env`のみ」という既存方針を崩さずに、UIからの設定変更が可能になった
- ローカルPC上で完結する運用のため、`.env`をUIから書き換えること自体のセキュリティリスクは限定的（多重ユーザー・リモートアクセスは想定していない、[ADR-0012](0012-primary-ui-with-telegram-as-secondary.md)参照）

### 悪い影響・トレードオフ

- `.env`ファイルへの書き込み権限が本体Webプロセスに必要になる（ローカル単一ユーザー運用のため許容）
- 秘密情報を画面に表示しない設計上、「設定済みだが値が間違っている」ケースの発見は`reelmilly doctor`等での疎通確認に頼ることになる
