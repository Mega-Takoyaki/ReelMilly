# 0005. デプロイ環境（AWS EC2 vs ローカルPC）

- ステータス: 提案中（未決定）
- 決定日: 未定
- 決定者: 未定

## コンテキストと課題

X投稿（[ADR-0002](0002-x-posting-via-playwright.md)）はPlaywrightの永続ブラウザプロファイルに依存し、ヘッドレス環境でのセッション維持が弱いという制約がある（CLAUDE_HANDOFF.md 14章）。この制約のもとで、ワーカーをどこで常駐させるかを決める必要がある。

## 検討中の選択肢

- ローカルPC（Windows）で常時起動
- AWS EC2等（GUI付きインスタンス + VNC等でX初回ログインに対応）

## 判断軸（README.md / docs/architecture.md 7章にも記載）

| 観点 | ローカルPC | AWS EC2等 |
|---|---|---|
| Playwright永続プロファイルの維持 | 容易 | ヘッドレスでは弱い |
| 24時間稼働の安定性 | PCの状態に依存 | 安定だがGUI付きはコスト増 |
| 初回Xログイン | そのまま可能 | VNC等の追加構成が必要 |
| 運用コスト | 電気代のみ | インスタンス費用が継続発生 |
| 秘密情報管理 | `.env`のみで完結 | Secrets Manager等の追加設計が必要 |
